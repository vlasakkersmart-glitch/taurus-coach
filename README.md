# Taurus Coach

Persoonlijke trainingsapp voor de Taurus UltraForce (PWA).

* Alle trainingsgegevens blijven op het eigen toestel (IndexedDB).
* Er staan geen persoonsgegevens of handleidingafbeeldingen in deze map.
* Handleidingfoto's en persoonlijke startgegevens worden in de app geïmporteerd via
  Instellingen → Back-up / pakket importeren.
